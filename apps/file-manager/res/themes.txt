# ==========================================================================
#  File Manager themes
# ==========================================================================
#  Each [Name] block is one theme. The block's name becomes its slug (lower
#  case, spaces -> hyphens) - e.g. [Original Blue] is "original-blue", which
#  is what you put in settings.txt to start in it, and what L1/R1 cycles.
#
#  Colours are #RRGGBB, or #RRGGBBAA when you need transparency (AA is the
#  alpha and comes last: 00 = clear, FF = solid; omit it for solid). Every
#  block inherits Original Blue, so it only lists the colours it changes.
#
#  Two files are read and merged each launch: the shipped res/themes.txt (the
#  built-ins) and YOUR copy at /dev_hdd0/tmp/file-manager/themes.txt, seeded
#  from the built-ins on first launch and never overwritten again. In your
#  copy: edit a block to override that built-in, delete a block to fall back to
#  the shipped version, or add a new [Name] block for a theme of your own.
#
#  Keys:
#    appBg            whole-screen background
#    divider          thin header / footer divider lines
#    panelFill        raised panel fill (breadcrumb bar, dialog body)
#    panelBorder      raised panel border
#    menuFill         side-menu slab fill
#    menuBorder       side-menu slab border
#    highlightFill    selected-row fill
#    highlightBorder  selected-row border
#    separator        hairline between rows
#    checkBorder      checkbox outline
#    checkFill        checkbox tick (when checked)
#    textPrimary      main label text
#    textSecondary    dim subtitle text
#    textOnHighlight  subtitle text over a highlighted row
#    scrim            dim layer behind a pop-up dialog
#    dialogFill       dialog body fill
#    dialogBorder     dialog body border
#    progressTrack    progress bar background
#    progressFill     progress bar fill
#    scrollTrack      scrollbar track
#    scrollThumb      scrollbar thumb
# ==========================================================================
